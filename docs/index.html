Pacote JS/TS

javascript_abrasileirado ⚡

Biblioteca JavaScript e TypeScript para validação de dados, tipos de domínio e máscaras no Frontend (React, Vue, Angular) e Node.js.

Uso no Frontend & Node

import { validateCPF, formatCPF } from 'javascript_abrasileirado';

const isValid = validateCPF('123.456.789-09');
const formatted = formatCPF('12345678909');
